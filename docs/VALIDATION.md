# 验证范围

## 游戏优化集成

- `OptimizerIntegrationTests` 从 Studio 首页打开优化窗口，检查重复打开和重新打开时重用同一个窗口。关闭优化窗口后，后台监控和实例锁继续生效。测试也检查已启用优化后以 `--tray` 模式启动、Studio 正常退出时恢复原优先级并释放锁。
- `GameBoostEngineSmoke` 使用临时启动的受控进程，验证路径选择、进程重新启动、暂停和取消勾选、恢复日志、日志写入重试、进程 ID 重用以及保留外部调整的优先级。
- 优化测试在临时目录中保存规则和恢复记录。结果验证了 CPU 优先级的调整和恢复，未采集实际游戏的帧率、帧时间或操作延迟。

## 画面增强与补帧的既有验证

- 默认离线检查：509 项，验证文件安装/撤回、日志解析、中文迁移、Windows 参数引用、窗口身份和 UI 布局。
- 完整检查：512 项，另含固定 mpv 的三种参数探测及只读 NVAPI/应用诊断；需要本地准备 mpv 和 NVIDIA 驱动。
- 新增补帧后的完整离线检查为 693 项：倍率映射、缺失/混用 SL 插件、PE 加载入口、坏包/许可校验、HMAC 安装日志、回滚、撤回、两按钮与倍率窗口均有覆盖。
- 补帧组件受控加载：私有测试进程加载固定 Aurora wrapper，调用并验证 WINMM `timeGetTime` 转发，正常退出。没有启动真实游戏，不将此检查视为 2×–6× 实际帧生成证据。
- 燕云补帧只读预检：WINMM 静态导入、匹配的原生 SL 2.14.16 FG 插件、DLSSG 310.9.16 及 VC++ x64 依赖检查通过；尚未逐倍率验收生成画面和帧时间。
- 本机受控 PotPlayer 副本：Direct3D 11 Present 路径记录 64 次 NR 求值，正常退出。
- 本机受控窗口捕获：生成的测试窗口经过 Windows Graphics Capture → 私有 mpv → NR，记录成功求值及 13 个桥接帧，正常退出。

运行时记录来自生成的测试画面，不代表所有游戏、网站、片源或当前用户会话均兼容。窗口捕获测试没有采集个人浏览器画面。私有 PotPlayer 自身可能写入其共享的媒体信息注册表项，不能视为完全隔离的播放器沙箱。

两个日志样本 `tests/neural-real.log` 和 `tests/potplayer-neural-real.log` 来自受控测试，个人路径已替换为固定 fixture 路径，仅用于验证“明确求值成功”和正常退出后的证据保留。安装组件或初始化成功不会被计作 NR 求值成功。
